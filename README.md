# Teacher Portal - Feni Model High School

Modernized teacher portal for Feni Model High School, migrated from legacy static HTML/JS to Vite + TypeScript.

## Features
- **Attendance Management**: Mark today's attendance and view history.
- **Student Database**: Access student details and photos for the assigned class.
- **Secure Authentication**: Supabase-powered login and password reset.
- **Performance**: Optimized build using Vite.

## Setup
1. Clone the repository.
2. Install dependencies: `npm install`
3. Configure environment variables in `.env` (use `.env.example` as a template).
4. Run development server: `npm run dev`
5. Build for production: `npm run build`

## Project Structure
- `src/`: TypeScript source files.
- `public/`: Static assets (icons, manifest).
- root: HTML entry points and config files.
